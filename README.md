# MacBook Pro — Private Sale

A responsive, single-product private-sale website for a MacBook Pro. It is intentionally static so it can be hosted on GitHub Pages without a backend.

## Before publishing

Edit these placeholders:

- `index.html`: exact MacBook model, chip, memory, storage, display, condition, battery health, accessories, receipt/purchase details, price, city, and shipping policy.
- `script.js`: set `SELLER_EMAIL` to the email address that should receive enquiries.
- Replace the four gallery placeholders with real device photos.

## Run locally

Open `index.html` directly in a browser, or use any static server, for example:

```bash
python3 -m http.server 4173
```

Then visit `http://localhost:4173`.

## Deploy

This project is static and suitable for GitHub Pages, Netlify, Vercel, Cloudflare Pages, or any static host.
