# MacBook Pro Ad Space

A Vite-powered single-page sponsorship site for physical advertising placements on a starlight MacBook Pro.

## Features

- Premium responsive UI with dark/gold product aesthetic.
- CSS-built 3D MacBook and companion iPhone renders; no generated image assets required.
- Interactive MacBook rotation/flip with pointer drag.
- Six priced ad-slot cards with live selection and booking email generation.
- Sponsor/brand wall and configurable physical placement markers.
- FAQ, campaign rationale, and mobile layouts.

## Run

```bash
npm install
npm run dev
```

Production build:

```bash
npm run build
```

Before publishing, replace `replace-with-your-email@example.com` in `src/main.js` with the seller contact address.
